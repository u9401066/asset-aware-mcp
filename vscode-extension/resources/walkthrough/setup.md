# Setup Asset-Aware MCP

Welcome to Asset-Aware MCP! This extension provides a Medical RAG MCP Server for precise document asset retrieval.

## Prerequisites

Before starting, make sure you have:

1. **Python 3.11+** installed
2. **uv** package manager (recommended) - [Install uv](https://docs.astral.sh/uv/getting-started/installation/)
3. **Ollama** (optional, for local LLM) - [Download Ollama](https://ollama.com/download)

## Quick Setup

Click the "Run Setup Wizard" button above to:

1. ✅ Create `.env` configuration file
2. ✅ Check Ollama connection
3. ✅ Initialize MCP server

## After Setup

Once configured, you can:

- 📄 **Ingest PDFs**: "Ingest this PDF document"
- 📊 **Extract tables**: "Get Table 1 from the document"
- 🖼️ **Extract figures**: "Show me Figure 2"
- 🔍 **Query knowledge**: "What does the paper say about X?"
